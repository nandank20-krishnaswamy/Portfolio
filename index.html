Sec. 01 — About

Fundamentals first, then the framework.

I'm a Computer Science Engineering student who treats markup and styling as seriously as the frameworks built on top of them. Before reaching for a library, I ask what plain HTML, CSS and JavaScript can already do — which is why every interface I ship is fast, accessible, and doesn't fall apart outside the happy path.

Recent work spans real-time data dashboards, AI-powered tools, and ML-backed decision systems — always with the same question at the center: what does the person using this actually need to see, and when?
